## 🧵 横断まとめ
<!-- LN:SYNTHESIS:START -->

### 疫学の地殻変動 — 「誰がかかる病気か」が入れ替わった

19世紀末の最初の記載以来、IE の疫学は大きく形を変えてきた。かつては構造的心疾患をもつ比較的若い患者の病気だったが、現在は多数の併存症を抱える高齢者と、医療行為そのものに関連した感染が中心になっている ([Rapti 2026](https://pubmed.ncbi.nlm.nih.gov/42515024/))。病原体の勢力図もこれに連動して入れ替わり、かつて最多だった viridans streptococci に代わって *Staphylococcus aureus* が首位に立った。その駆動因子として繰り返し挙がるのが、注射薬物使用の増加と医療関連感染の二つである ([Bogni 2026](https://pubmed.ncbi.nlm.nih.gov/42405366/))。Global Burden of Disease のデータでは罹患の実数自体が増加傾向にあると報告されており、「稀だが重い病気」から「増えつつある重い病気」へと位置づけが動きつつある ([Di Vito 2026](https://pubmed.ncbi.nlm.nih.gov/42041981/))。

一方で転帰の重さは更新されていない。院内死亡は 15〜25%、1年死亡は 40% に迫り、症例の 40〜50% が外科手術を必要とする ([Ishak 2026](https://pubmed.ncbi.nlm.nih.gov/42192704/) / [Abd Rani 2026](https://pubmed.ncbi.nlm.nih.gov/42469863/))。疫学が変わっても死亡率が下がっていないという事実が、以下のテーマ群すべての背景圧力になっている。

### 弁は平等ではない — 部位ごとの構造的脆弱性

IE は弁に一様に分布しない。大動脈弁 30〜45%、僧帽弁 25〜30%、三尖弁 5〜10%、肺動脈弁 <2%、人工弁 10〜30% という偏りは偶然ではなく、弁ごとの構造・血行動態・受ける剪断応力の違いを反映している。そしてこの分布の違いが、そのまま手術の複雑さ (弁輪膿瘍・弁周囲破壊への到達しやすさ) と術後転帰の差につながる、という視点が narrative review として整理された ([Abd Rani 2026](https://pubmed.ncbi.nlm.nih.gov/42469863/))。「IE の予後」を一つの数字で語ることの限界を示す枠組みで、後述の右心系 IE の扱いとも接続する。

### デバイス時代の IE — TAVI・TEER・sutureless 弁

経カテーテル治療の急拡大は、IE に新しい病型を持ち込んだ。TAVI 関連 IE は、全体の発生率こそ相対的に低いものの、いざ起これば高い罹病率・死亡率を伴う臨床課題として立ち上がっている ([Dădârlat-Pop 2026](https://pubmed.ncbi.nlm.nih.gov/42499544/))。僧帽弁の transcatheter edge-to-edge repair (M-TEER) デバイスも同様で、TAVR/TEER 双方について「診断を遅らせないための多職種アプローチ」と「一部症例での外科介入」が要点として繰り返される ([Aoun 2026](https://pubmed.ncbi.nlm.nih.gov/42489383/))。外科側でも、良好な血行動態と手術時間短縮を売りに普及した Perceval sutureless 弁が同じ問題を抱え、発生率・診断上の難所・管理方針が expert opinion としてまとめられた ([Rello 2026](https://pubmed.ncbi.nlm.nih.gov/41897624/))。

この三者に共通するジレンマは構造的である。人工物は心エコーの音響窓を汚して診断を難しくし、しかもこれらのデバイスが選ばれた患者は「高齢・高手術リスクだから低侵襲を選んだ」層と重なる。つまり最も診断が難しい集団が、最も外科的救済に戻りにくい。ここが真菌性 IE や画像診断のテーマと直結する交差点になる。

### 診断 — 心エコーの序列と、培養からメタゲノムへ

心エコーについては、TEE と TTE の診断精度を直接比較したメタ解析が出て、IE 検出における TEE の優位が改めて定量化された ([Yang & Zhang 2026](https://pubmed.ncbi.nlm.nih.gov/42088705/))。ただし人工弁・デバイス例では TEE でも限界があり、そこを埋めるのが多モダリティ画像である。真菌性 IE (FIE) のレビューは、高齢化・人工弁・植込み型心臓デバイス・免疫抑制の増加という母集団の変化を背景に、稀ながら診断・治療の両面で固有の難しさを持つ病型として画像診断の役割を整理している ([Kalinski & Xu 2026](https://pubmed.ncbi.nlm.nih.gov/42428660/))。

微生物学的診断の側では、より根本的な転換が進む。培養主体から次世代シーケンス／メタゲノム解析へというパラダイムシフトは、培養陰性 IE という長年の空白を埋める方向にあり、IE を「世界で3番目に多い致死的感染症」と位置づけたうえでその臨床的負荷を論じるレビューが出た ([ElHefnawi 2026](https://pubmed.ncbi.nlm.nih.gov/42085838/))。同じ流れの先に、遺伝的素因を含む包括的リスクプロファイリングから早期検出・個別化管理へつなぐ precision medicine の構想が置かれている ([Casallas-Barrera 2026](https://pubmed.ncbi.nlm.nih.gov/42017938/))。ただし現時点では構想が先行しており、臨床アウトカムでの検証はこれからである。

### 右心系 IE と注射薬物使用 — PFO・経皮的機械的吸引

注射薬物使用 (IVDU) は IE の主要リスク因子で、右心系 IE (RSIE) が最も多い。その弁別分布と RSIE の相対リスクを定量化したメタ解析が出て、これまで曖昧だった数字に輪郭がついた ([Le 2026](https://pubmed.ncbi.nlm.nih.gov/42121066/))。ここに重なるのが卵円孔開存 (PFO) の問題で、「注射薬物使用 + RSIE + PFO」の組み合わせが体循環系塞栓を起こす症候群として系統的にレビューされた ([Cuervo 2026](https://pubmed.ncbi.nlm.nih.gov/42169692/))。右心系だから脳塞栓は考えなくてよい、という直感が通用しない集団があるということで、RSIE 例での PFO 検索の閾値を下げる方向に働く知見である。

治療面では、経皮的機械的吸引 (PMA) が新たな選択肢として前に出た。もともと血栓摘除用に開発されたカテーテル技術を疣贅の source control に転用するもので、抗菌薬への反応が不十分な例や手術高リスク例を対象とする位置づけが AHA science advisory としてまとめられ ([El Sabbagh 2026a](https://pubmed.ncbi.nlm.nih.gov/42095279/))、三尖弁 IE (TVIE) に絞った各論も併せて出ている ([El Sabbagh 2026b](https://pubmed.ncbi.nlm.nih.gov/41988451/))。TVIE 自体が注射薬物使用と植込み型心臓デバイス (CIED) の増加で増えており、需要が技術を引き寄せた形といえる。なお advisory は比較試験ではなく専門家の位置づけ整理であり、エビデンスの階段はまだ下段にある。

### 治療 — 抗菌薬の新しい形と、修正しうる予後因子

抗菌薬側で最も議論が動いているのは長時間作用型リポグリコペプチドの dalbavancin である。有効性・安全性・投与量を扱った系統的レビューに対して comment と reply が応酬される形になっており ([Lohana 2026](https://pubmed.ncbi.nlm.nih.gov/42257986/) / [Chaldoupis 2026](https://pubmed.ncbi.nlm.nih.gov/42429893/))、外来静注抗菌薬療法 (OPAT) や入院短縮という魅力の一方で、至適投与量とエビデンスの質が未決着であることを示している。耐性側では、バンコマイシン耐性腸球菌 (VRE) による IE の症例集積 + 2000〜2024年の文献レビューが、疫学・管理・死亡予測因子を初めてまとまった形で提示した ([Cairns 2026](https://pubmed.ncbi.nlm.nih.gov/42235917/))。

外科と周術期では、「手術そのものの技術」より「手術に送り込むまでの状態」に焦点が移りつつある。術前アルブミン値と術後死亡の関連を扱ったシステマティックレビュー／メタ解析は、術前最適化という介入可能な余地を示唆する ([Thet 2026](https://pubmed.ncbi.nlm.nih.gov/42493841/))。補助療法としてはスタチンの多面的効果 (pleiotropic effects) が塞栓イベントと死亡に及ぼす影響がメタ解析され ([Hannachi 2026](https://pubmed.ncbi.nlm.nih.gov/41926297/))、IE 発症頻度そのものへの影響も検討されている。

これらを束ねる運用上の答えとして繰り返し出てくるのが、多職種 endocarditis team である。感染症科・循環器・心臓外科・画像・(薬物使用例では) 依存症治療を横断する体制と、未充足の臨床ニーズの所在を整理したレビュー ([Di Vito 2026](https://pubmed.ncbi.nlm.nih.gov/42041981/))、および診断から治療までを俯瞰した scoping review ([Bogni 2026](https://pubmed.ncbi.nlm.nih.gov/42405366/)) が、この時期の総説群の中核をなす。

### 症例が示す辺縁 — 稀な病原体と重なり合う病態

総説群の外側に、教科書の枠に収まらない症例報告が並ぶ。*Streptococcus sinensis* による IE が細菌性髄膜炎を合併した例は、両下肢の虚血症状という非典型的な入口から始まり、心エコーで僧帽弁疣贅が見つかっている ([Yang L 2026](https://pubmed.ncbi.nlm.nih.gov/42136553/))。ワクチン接種済みのアイルランドの小児2例に肺炎球菌 IE が発生した報告は、非ワクチン血清型と宿主免疫の問題を突きつける — 1例目は多発性骨髄炎・化膿性関節炎に続いて IE を発症した ([Crowley 2026](https://pubmed.ncbi.nlm.nih.gov/41951923/))。デング熱流行地では、デング感染に続発した IE が脳・腎・肝・脾の多臓器梗塞、脳膿瘍、Horner 症候群まで引き起こした例が報告された ([Sulaiman 2026](https://pubmed.ncbi.nlm.nih.gov/41876992/))。

やや毛色が違うが、ブロイラー鶏の *Vagococcus fluvialis* による鳥類 IE の報告も収集に含まれる ([Chacón 2026](https://pubmed.ncbi.nlm.nih.gov/42072033/))。ヒト臨床の直接の材料ではないものの、*Vagococcus* はヒト IE でも稀に報告される属であり、One Health 的な検出系・病原性の参照として位置づけられる。
