## 📌 5行サマリ
<!-- LN:SUMMARY:START -->
- 電子カルテ情報共有サービスは「全国医療情報プラットフォーム」の中核で、**3文書6情報** (診療情報提供書・退院時サマリー・健診結果 / 傷病名・アレルギー・感染症・薬剤禁忌・検査・処方) を全国の医療機関・薬局・本人が閲覧できるようにする仕組み
- 現在地 (2026-09): **全国9地域のモデル事業**で検証中。判明した課題の改修を経て**2026年度冬頃の全国展開開始**を目指す段階。2026年9月には患者サマリー閲覧系のシステムリリースが予定に載った
- 外堀は法律で埋まった: 2025年12月成立の改正医療法等で**2030年12月末までに電子カルテ普及率100%**が明文化 (直接の義務化ではないが、政策圧力は明確)。未導入の医科クリニックは約4.7万施設 — 普及の主戦場は診療所
- 診療所の実務は「**急いで飛び乗る必要はないが、逆算は始める**」が現在の相場: オン資ネットワークが土台、費用は支払基金ポータルの補助金枠、算定面は医療DX推進体制整備加算の要件変化をウォッチ
- 家庭医にとっての本丸は**紹介状・退院時サマリーが電子で届き、初診の情報格差 (お薬手帳忘れ・アレルギー不明) が縮む**こと。「書く負担」より「探す負担」が減る改革と読む
<!-- LN:SUMMARY:END -->

## 🧵 横断まとめ
<!-- LN:SYNTHESIS:START -->

### 1. これは何 — 3文書6情報を「全国どこでも」に
電子カルテ情報共有サービスは、医療機関同士が患者の電子カルテ情報の要点を共有し、本人もマイナポータル経由で自分の情報を見られるようにする国のインフラ ([厚労省ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/johoka/denkarukyouyuu.html))。共有されるのは:

| 区分 | 中身 |
|---|---|
| **3文書** | 診療情報提供書 (紹介状) / 退院時サマリー (紹介状に添付) / 健診結果報告書 |
| **6情報** | 傷病名 / アレルギー / 感染症 / 薬剤禁忌 / 検査 (救急・生活習慣病) / 処方 |

オンライン資格確認 (マイナ保険証) のネットワークが土台で、患者の同意を介して他院の情報を閲覧する。電子処方箋・電子カルテ標準化 (HL7 FHIR) と並ぶ「医療DX令和ビジョン2030」の3点セットの一角。

### 2. 年表 — どこまで来て、何が残っているか
- **2023**: 医療DX推進体制整備の政府方針。仕組みの設計・仕様公開が進む
- **2025**: 全国**9地域でモデル事業**開始。システムベンダ対応状況の公開 (2025-02)。運用しながら課題洗い出し
- **2025-12**: **改正医療法等が成立** — 2030年12月末までの電子カルテ普及率100%目標を法律に明記
- **2026**: モデル事業で見つかった課題の検証・改修フェーズ ([医療等情報利活用WG 第33回](https://www.mhlw.go.jp/stf/newpage_49537.html) が2026-06-26開催、技術解説書 v2.1.0 も6月公開)。**2026-09 に患者サマリー登録・閲覧系のシステムリリース予定**
- **2026年度冬頃**: **全国展開の開始目標** ([GemMed 報道](https://gemmed.ghc-j.com/?p=71681)、[日経メディカル](https://medical.nikkeibp.co.jp/leaf/mem/pub/report/t391/202512/591423.html))
- **2026年度中**: 診療所向け**標準型電子カルテ**の本体完成目標 (2025年からα版モデル事業が先行)
- **2030-12**: 電子カルテ普及率100%の法定目標年

### 3. 診療所に来る実務 — 費用・加算・準備
- **前提装備**: オンライン資格確認の回線 (ほぼ全院導入済み) + 対応した電子カルテ。自院のベンダが対応済みかは厚労省公開の**システムベンダ対応状況**で確認できる
- **費用と補助**: 導入改修費には補助金枠があり、申請・要件は[支払基金の医療機関等向け総合ポータル](https://iryohokenjyoho.service-now.com/csm)で告知される。金額・期限は変動するので都度確認 (このノートでは固定値を書かない)
- **算定面**: 医療DX推進体制整備加算の要件に電子カルテ情報共有サービスへの参加が段階的に組み込まれていく見込み。2026年度 (令和8年度) 診療報酬改定は AI・ICT 活用促進を打ち出しており、参加インセンティブは強まる方向 (二次情報: [2026年義務化解説](https://www.yuyama.co.jp/column/medicalrecord/duty/))
- **紙カルテ院の選択肢**: 焦って高額システムに飛びつかなくても、国の**標準型電子カルテ (導入版)** が「紙の業務はそのままに国の医療DXへ接続する」コンセプトで準備中 ([ウィーメックス解説](https://www.phchd.com/jp/medicom/park/tech/ehr-karte-standardization))。2026年度中の完成目標なので、更新期が近い院は「標準型を待つ/待たない」の分岐を意識
- **準備リスト (今日できること)**: ①自院カルテベンダの対応予定を聞く ②補助金ポータルの通知購読 ③院内の同意取得フロー (窓口での患者説明) を粗くイメージ ④6情報の入力品質 (病名整理・アレルギー欄) を平時から整える — 共有されて恥ずかしくないカルテは一朝一夕にならない

### 4. 見通しと不確実性 — 鵜呑みにしない読み方
- **スケジュールは一度ずれた前科がある**: 当初はもっと早い本格運用が語られていたが、モデル事業で課題が出て「2026年度冬頃」に再設定された経緯がある。**「目指す」は「確定」ではない** — 冬に再延期の報が出ても驚かない構え
- **普及率100% (2030) の実力**: 未導入4.7万クリニックの多くは高齢院長・更新投資に慎重な層。法定目標と現場の投資判断の間には摩擦が残り、期限直前の駆け込み・経過措置の追加はあり得る
- **共有される情報の「質」問題**: 6情報は入力されて初めて意味を持つ。病名の付け方・アレルギー欄の運用が院ごとにバラバラなままだと「繋がったのに読めない」が起きる — 制度が繋ぐのは配管で、水質は現場持ち
- **患者側の受け止め**: マイナ保険証への信頼・同意 UI の分かりやすさが利用率を左右する。本人閲覧 (患者サマリー) が動き出す 2026-09 以降、患者からの「これ何？」質問が外来に来る — 家庭医は説明の最前線になる
- **ウォッチポイント**: 医療等情報利活用WGの資料 (次回以降) / 全国展開開始のアナウンス / 診療報酬改定での要件化 / 標準型電カル本体のリリース

### 5. 家庭医にとっての意味 — 何が変わるか
- **初診・救急の情報格差が縮む**: 「お薬手帳忘れました」「アレルギーは…何かあった気がする」への保険が効く。特に多疾患併存の高齢患者で効果が大きい
- **紹介状・退院時サマリーの電子化**: 郵送・FAX・患者手渡しの摩擦が減り、逆紹介の返書も追いやすくなる。**書く負担が減るというより「探す・待つ・転記する」負担が減る**改革
- **かかりつけ医機能との相性**: 患者の全体像を継続的に把握する家庭医の仕事は、断片情報の集約コストが下がるほど楽になる。制度の設計思想と家庭医療の思想は同じ方向を向いている
- **AI 活用の土台にもなる**: 構造化された 6情報・電子文書が流れ始めると、カルテ AI (ambient scribe や要約 AI) の材料も揃う。姉妹ノート [copilot-healthcare](copilot-healthcare.ja.md) §8 の「制度と製品の交点」はここ
